# EPIC-11 — iOS Application

## Description
Extends portfolio reach by providing a native iOS application for mobile users to explore profiles, experience, projects, and articles.

---

### US-032 — View Portfolio on iOS
**User Story:**
> As a visitor,  
> I want to browse the portfolio from an iOS application,  
> so that I can access the professional information from my mobile device.

**Priority:** `Should Have`

---

### US-033 — View Projects on iOS
**User Story:**
> As an iOS user,  
> I want to browse portfolio projects,  
> so that I can explore the Portfolio Owner's work from the mobile application.

**Priority:** `Should Have`

---

### US-034 — Read Articles on iOS
**User Story:**
> As an iOS user,  
> I want to browse technical articles,  
> so that I can discover the Portfolio Owner's technical content.

**Priority:** `Should Have`
