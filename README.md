# Architect Portfolio Platform

A multi-platform professional portfolio system for presenting a software engineer's profile, projects, articles, experience, and skills — with an admin dashboard to manage all of it without touching code.

## Components

- **web** — public portfolio website
- **dashboard** — admin dashboard for managing portfolio content
- **ios** — iOS mobile application
- **Backend** — RESTful API and database
- **docs** — requirements, architecture (ADRs, C4 diagrams), and design documentation

## Status

Early stage — architecture and requirements are being defined (see [docs/](docs)) before implementation begins.
