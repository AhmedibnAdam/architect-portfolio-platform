# EPIC-06 — Articles

## Description
Manages and displays technical articles, publications, thought leadership, and external blog posts.

---

### US-017 — View Articles
**User Story:**
> As a visitor,  
> I want to view technical articles,  
> so that I can explore the Portfolio Owner's technical knowledge.

**Priority:** `Must Have`

---

### US-018 — View Article Details
**User Story:**
> As a visitor,  
> I want to view article information,  
> so that I can understand the topic before opening the external article.

**Priority:** `Must Have`

---

### US-019 — Open External Article
**User Story:**
> As a visitor,  
> I want to open the original article,  
> so that I can read the complete content on the external platform.

**Priority:** `Must Have`

---

### US-020 — Add Article
**User Story:**
> As the Portfolio Owner,  
> I want to add an article,  
> so that I can showcase my latest technical writing.

**Priority:** `Must Have`

---

### US-021 — Publish Article
**User Story:**
> As the Portfolio Owner,  
> I want to control the publication status of an article,  
> so that I can prepare content before making it publicly available.

**Priority:** `Should Have`
