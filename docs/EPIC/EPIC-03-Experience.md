# EPIC-03 — Experience

## Description
Manages and displays the Portfolio Owner's career history, work experience, roles, and employment timeline.

---

### US-005 — View Experience
**User Story:**
> As a visitor,  
> I want to view professional experience,  
> so that I can understand the Portfolio Owner's career history.

**Priority:** `Must Have`

---

### US-006 — Add Experience
**User Story:**
> As the Portfolio Owner,  
> I want to add a professional experience entry,  
> so that I can keep my career history up to date.

**Priority:** `Must Have`

---

### US-007 — Edit Experience
**User Story:**
> As the Portfolio Owner,  
> I want to edit an existing experience entry,  
> so that I can correct or update my professional information.

**Priority:** `Must Have`

---

### US-008 — Remove Experience
**User Story:**
> As the Portfolio Owner,  
> I want to remove an experience entry,  
> so that outdated information is no longer displayed.

**Priority:** `Must Have`
