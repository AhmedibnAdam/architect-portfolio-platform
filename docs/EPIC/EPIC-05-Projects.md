# EPIC-05 — Projects

## Description
Showcases practical engineering experience, software applications, business solutions, and technical implementations.

---

### US-012 — View Projects
**User Story:**
> As a visitor,  
> I want to view the Portfolio Owner's projects,  
> so that I can understand their practical engineering experience.

**Priority:** `Must Have`

---

### US-013 — View Project Details
**User Story:**
> As a visitor,  
> I want to view detailed information about a project,  
> so that I can understand its purpose, technology, and architecture.

**Details Attributes:**
- Project description
- Business problem solved
- Role & Responsibilities
- Key technologies used
- Architectural highlights
- GitHub repository links
- Live application links

**Priority:** `Must Have`

---

### US-014 — Add Project
**User Story:**
> As the Portfolio Owner,  
> I want to add a project,  
> so that I can showcase new work.

**Priority:** `Must Have`

---

### US-015 — Edit Project
**User Story:**
> As the Portfolio Owner,  
> I want to edit project information,  
> so that project information remains accurate.

**Priority:** `Must Have`

---

### US-016 — Delete Project
**User Story:**
> As the Portfolio Owner,  
> I want to remove a project,  
> so that outdated projects are no longer displayed.

**Priority:** `Must Have`
