# EPIC-08 — CV

## Description
Handles the viewing, downloading, and uploading of the Portfolio Owner's latest Curriculum Vitae (CV) / Resume.

---

### US-024 — View CV
**User Story:**
> As a visitor,  
> I want to access the Portfolio Owner's CV,  
> so that I can review their complete professional history.

**Priority:** `Must Have`

---

### US-025 — Download CV
**User Story:**
> As a visitor,  
> I want to download the CV,  
> so that I can save it for later review.

**Priority:** `Must Have`

---

### US-026 — Update CV
**User Story:**
> As the Portfolio Owner,  
> I want to update my CV,  
> so that visitors can access the latest version.

**Priority:** `Must Have`
