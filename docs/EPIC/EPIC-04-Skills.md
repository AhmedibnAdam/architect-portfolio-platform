# EPIC-04 — Skills

## Description
Organizes, categorizes, and displays technical capabilities, tools, methodologies, and architectural proficiencies.

---

### US-009 — View Skills
**User Story:**
> As a visitor,  
> I want to view the Portfolio Owner's technical skills,  
> so that I can understand their technical capabilities.

**Priority:** `Must Have`

---

### US-010 — Categorize Skills
**User Story:**
> As the Portfolio Owner,  
> I want to organize skills into categories,  
> so that visitors can understand my expertise more easily.

**Example Categories Structure:**
- **Mobile**
  - Swift
  - UIKit
  - SwiftUI
- **Backend**
  - C#
  - ASP.NET Core
  - Entity Framework Core
- **Architecture**
  - DDD
  - Clean Architecture
  - CQRS

**Priority:** `Must Have`

---

### US-011 — Manage Skills
**User Story:**
> As the Portfolio Owner,  
> I want to add, edit, and remove skills,  
> so that my technical profile remains current.

**Priority:** `Must Have`
