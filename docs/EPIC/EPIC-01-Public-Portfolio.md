# EPIC-01 — Public Portfolio

## Description
Provides visitors with immediate access to the portfolio homepage, allowing them to view high-level professional information and seamlessly navigate between major portfolio sections.

---

### US-001 — View Portfolio
**User Story:**
> As a visitor,  
> I want to view the portfolio homepage,  
> so that I can quickly understand who the Portfolio Owner is and what they do.

**Acceptance Criteria:**
- Visitor can access the portfolio without authentication.
- Professional identity is clearly displayed.
- Main professional areas are visible.
- Visitor can navigate to major portfolio sections.

**Priority:** `Must Have`

---

### US-002 — Navigate Portfolio
**User Story:**
> As a visitor,  
> I want to navigate between portfolio sections,  
> so that I can easily find the information I need.

**Supported Sections:**
- About
- Experience
- Skills
- Projects
- Articles
- CV
- Contact

**Priority:** `Must Have`
